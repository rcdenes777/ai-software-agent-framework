# AI Software Agent Framework

Framework de skills, templates e padrões para agentes de IA voltados ao desenvolvimento de software.

## Objetivo

Criar uma arquitetura reutilizável de agentes onde:

- um Gerente Técnico planeja e coordena;
- um Executor implementa tarefas;
- especialistas auxiliam em áreas específicas.

## Arquitetura

Fluxo principal:

Usuário
↓
Project Manager
↓
Task Executor
↓
Implementação
↓
Revisão
↓
Atualização do projeto

## Skills principais

### project-manager-core

Gerenciamento técnico de projetos.

Responsável por:

- visão do projeto;
- requisitos;
- escopo;
- roadmap;
- fases;
- tarefas;
- critérios de aceite;
- acompanhamento;
- handoff.

### task-complexity-analyzer

Avaliação de complexidade das tarefas.

Níveis:

- Lua
- Terra
- Sol

### test-engineering-core

Estratégia e revisão de testes.
